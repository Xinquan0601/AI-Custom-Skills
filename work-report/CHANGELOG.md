# CHANGELOG

## 1.0.0 — 2026-11-04

第一个可用版本。

- 周报/月报双产出，周次口径周二到周一，月报只合并周报、不重读日志
- 分类三级：标题板号 → 仓库名 → 忽略清单，兜底进非工作「其他」组
- 工作四系列 `DV460 / DV454 / DV456 / DV436`，客户组按首字母排序，周报月报同序
- 条目字数区间 60–120，渲染器 <40 或 >120 报警，非工作关闭下限
- `render.py` 8 类硬校验 + `monthly.py` 漏写会话核对
- `scripts/selfcheck.py`：最小数据包跑通全链路
- 索引页支持 `file://` 下连接文件夹、编辑保存 md

### 相对 0.x 的变化

- 兜底组由「杂项」统一为「其他」，与文档一致
- 去掉「手改稿自动备份到 `_历史/`」的说明，该功能未实现，不再承诺
- 补齐非工作分组（工具链 / 个人项目 / 其他）的文档
- 补 `version` 字段、README、本文件、自检脚本
- 仓库只留技能本体与说明，参考报告、参考流程、数据包样例等已清理
