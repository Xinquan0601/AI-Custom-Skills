## 分类优先级

判定一条会话归属某个系列/客户，按顺序匹配，先命中先算：

1. **标题里的板卡记号**（`projects.board_hints`）：出现 `Code3`/`alpine` → DV454 Alpine；`456FTC` → DV456-FTC1；`rk3576`/`dv460` → DV460；`dv424`/`drawio` → DV454 通用板。
2. **仓库目录名**（`projects.work`）：`prj-mdvrv1` → DV454 通用板，`prj-dv454-xieli` → DV454 xieli 客户。
3. 都命中不了 → 未归类，人工裁决后补规则，不要硬塞。

标题优先于仓库名，因为 `prj-mdvrv1` 同一个仓库同时编 DV424 和 DV456 两个板子的固件。

## 非工作

工作目录和标题都认不出项目的内容，一律进非工作，产出写到另一个目录（非工作记录/），分组只有三档：

| 组 | 装什么 | 例子 |
|---|---|---|
| 工具链 | 采集器、插件、skill、配置这类自己造的工具 | AI 聊天记录收集器、drawio-skill、opencode 配置 |
| 个人项目 | 有交付物的私活、店铺、硬件小项目 | 赣南脐橙店铺、ESP32 端口层、租房分析 |
| 其他 | 认不出来的兜底 | 一次性问答、环境配置、与本职工作无关的杂事 |

判定顺序：`projects.nonwork` 的 `match` 先命中先算，最后兜底 `其他`。非工作条目不带系列，
标题写 `# 非工作周报 | <周期>`，正文二级标题就是组名。

## 忽略

`projects.ignore` 里的记号命中即不算工作内容（`hello.py`、`note.md`、`OK` 指令、单词回复等）。测试桩、问答、闲聊不计入周报。
