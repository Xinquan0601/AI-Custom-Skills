# ADR-0001: 实质会话口径保持 2 条用户消息 + 1 分钟，快速问答单独计数

「实质会话」是统计主口径（所有会话数、占比、推断类图表的基础），历史报告可比性依赖它跨期不变。因此保持 `user_message_count >= 2 且 duration_minutes >= 1` 的定义不动，但同时承认单条问答也是真实使用——在副标题与统计行里以「另 M 个快速问答」显式补充，而不是改口径把轻量使用并入主数字。

改口径看似简单（放宽到 1 条消息即可），代价是破坏与全部旧报告、旧 history 存档的可比性——环比功能（ADR-0002）上线后这个代价更高。补充显示是零成本的信息增益，两全。
