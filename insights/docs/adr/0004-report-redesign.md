# ADR-0004：报告按「数据 → 判断 → 行动」重排，图表只保留说话的那些

- 状态：已采纳（2026-11-05）
- 相关决策：D3（结构可以重新设计）、D4（旧报告模板不再沿用）

## 背景

旧报告沿用参考项目的 12 张图表（目标分类、满意度、会话结果、摩擦枚举…）。这些枚举是为
通用 Claude Code 场景设计的，套到「RK3576 设备树验证」「拼多多商品上架」上语义立刻散掉；
而真正有信号的东西——工具能力分布、项目集中度、报错类型、并行度——反而没有位置。

## 决策

报告结构改为：

1. **封面与统计卡**：会话 / 消息 / 工具调用 / 代码行 / 活跃天数 / token（带覆盖率说明）。
2. **总览四件事**：做得好、拖后腿、可立刻试、进阶工作流。
3. **环比**：只有周报 / 月报才有上期，其他窗口明确写「不做自动环比」（ADR-0002）。
4. **Agent 分工**：会话、消息、工具量、报错率。
5. **项目**：消息量排序 + 一句话说明（来自 narratives）。
6. **工具**：能力族堆叠条 + Top 工具表 + 每族最常用工具。
7. **产出**：文件数、代码行、语言分布（按去重文件）。
8. **节奏**：每天消息、24 小时热力、响应时间分布、多会话并行。
9. **摩擦**：报错类型、报错最多的工具、真实样本。
10. **叙事**：风格、亮点、复盘、建议、展望、趣味结尾。
11. **口径页脚**：实质会话定义、事件计数口径、数据质量说明。

## 放弃的东西

- 目标分类 / 满意度 / 会话结果 / 摩擦枚举等语义计数：无法从导出包可靠推断，容易变成 LLM 编造。
- 12 张固定图表：改为「有几类数据就画几张」，缺数据时整块跳过而不是画一张空图。
- Google Fonts 等外部依赖：报告必须离线可开。

## 影响

- `stats.schema_version` 升到 2；`narratives` 契约同步重写（去掉语义枚举，保留可追溯的 `source`）。
- 报告可以没有某一块（比如没有代码改动就没有产出区），但**不能有假的块**。
