# ADR-0002: 环比定位按周期类型（周/月），不做紧邻窗口对比

报告内「本期 vs 上期」区块需要确定「上期」是哪个窗口。选择：按报告类型定位——周报（`--week this`）找上一自然周（周一到周五）的 history 存档，月报（`--month this`）找上一自然月。拒绝「窗口紧邻的上一份」方案：它虽然灵活（任意窗口都有对比），但上期可能是 7 天、本期 3 天，口径错位会让差值失真——「消息数翻倍」可能只是窗口长了四天，这是洞察报告最危险的误导。

类型对齐的代价是任意日期范围（如 8月10到15号）没有自动环比，因此保留 `--compare <路径>` 手动逃生舱。首次运行无上期存档时，区块显示「首次生成，无上期数据」并跳过，不报错。
